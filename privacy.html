Privacy policy

Effective October 15, 2026

Hermes integration is a private, non-commercial tool used only by its owner. Google user data is accessed solely to fulfill the owner’s requests.

Who operates this integration

This integration is operated by an individual developer for personal use. It is not a company, public application, or service offered to other users.

Google data accessed

Depending on permissions granted by the owner, the integration may access Gmail messages and labels, Calendar events, Drive files, Docs, Sheets, and basic Contacts information.

How data is used

Data is used only to perform actions explicitly requested by the account owner, provide requested summaries or automation, and maintain the authorized connection. Google user data is not used for advertising, sold, rented, or shared with data brokers.

Storage and security

OAuth credentials are stored in the owner’s private Hermes environment. Task outputs and temporary working data are handled within systems controlled by the owner. Temporary data is removed when it is no longer needed for the requested task.

AI and model use

Google user data is not used to train public or shared artificial-intelligence models. When the owner asks Hermes to process Google content, only the information needed for that request is provided to the configured processing service.

Sharing

Data is not disclosed to unrelated third parties. It may be processed by Google, the owner’s Hermes environment, and the model provider selected by the owner solely as necessary to complete an owner-requested task.

Retention and deletion

The owner controls retained files and can delete task artifacts, revoke Google access, or remove the local OAuth token at any time. Revoking access prevents future Google API access.

Limited Use disclosure

The integration’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions about this policy can be raised through the Gulliksen Home GitHub profile.
